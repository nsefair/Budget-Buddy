# Security Policy

## Supported versions

Security fixes are applied to the latest commit on `main`. This repository is
a portfolio-stage application and is not represented as a production financial
service.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include
credentials, personal data, or exploit details in a public discussion.

Use GitHub's **Report a vulnerability** button on the repository Security page
to submit a private vulnerability report. Include the affected component,
reproduction steps, impact, and any suggested remediation. The maintainer will
acknowledge the report and coordinate disclosure after a fix is available.

## Scope notes

- Never submit real bank, Plaid, SMTP, billing, database, or signing secrets.
- The checked-in environment files contain placeholders only.
- Sandbox and mock behavior is not a production security guarantee.
